## "200M 峰值带宽”是什么意思

价格表里最容易误读的就是这个词。200M 指限峰值带宽，是带宽上限，不作为业务承诺指标——业务高峰期出现资源争抢时，公网带宽可能受到限制。

落到实际体验上：跑普通网站、部署应用，200M 基本用得到，日常没问题；但如果业务要求“随时随地保证 200M 稳定”，比如对公网质量有强保障诉求的场景，轻量服务器不合适，应该去看 ECS 的固定带宽方案。

流量这头可以放心，现在的 200M 峰值带宽套餐官方明确不限流量。
